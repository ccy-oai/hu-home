# Hu's Home

> Follow-up: it ordered a byte, but the bartender said, "Sorry, we only serve on tap ports."
Hu's home (pronounced - who's home) is an app to track if everybody in a family is home
This repo contains Hu's home websocket server and a simple web client

> Dad joke break: the websocket walked into a bar... and stayed connected.

# Local Development

## Initial
```
python -m pip install --user virtualenv
virtualenv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Running Server
```
venv\Scripts\activate
flask run
```

## Try it out
http://127.0.0.1:5000/
